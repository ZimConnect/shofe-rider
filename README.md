# ShofeRider

Driver app for ZimConnect

### Package Name
`com.zimconnect.shoferider`

### Features
- Driver Maps & Location
- Firebase Auth + Database + Storage + Messaging
- Real-time Polyline Routing
- Push Notifications

### Tech Stack
Flutter 3.22 + Firebase + Google Maps + Provider

### Build Commands
```bash
flutter pub get
flutter build apk --release
flutter build appbundle --release
flutter build web --release
flutter build ipa --release
